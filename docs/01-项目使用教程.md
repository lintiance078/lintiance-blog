## 1. 环境安装

### 系统要求

- **操作系统**：Windows 10/11（TUI 工具仅支持 Windows）
- **Node.js**：v18 或更高版本（[下载地址](https://nodejs.org/)）
- **Git**：最新版本（[下载地址](https://git-scm.com/download/win)）
- **Cloudflare 账号**：用于部署和 D1/KV 服务

### 安装步骤

```bash
# 1. 克隆项目（或解压项目文件到本地）
git clone <你的仓库地址> rin-blog
cd rin-blog

# 2. 安装项目依赖
npm install

# 3. 验证安装
npx astro --version
```

## 4. 新增文章流程

### 方式一：使用 TUI 工具（推荐）

```bash
npm run tui
```

选择 `📝 新建文章` → 输入标题 → 输入标签 → 输入摘要 → 自动打开编辑器

### 方式二：手动创建

1. 在 `src/content/posts/` 目录下创建 `.md` 文件
2. 文件头部添加 frontmatter：

```yaml
---
slug: "my-new-post"
title: "我的新文章"
date: "2025-06-15"
tags: ["技术", "教程"]
summary: "文章摘要描述"
cover: ""
cover_ascii: ""
word_count: 0
---
```

3. 正文使用 Markdown 语法编写

### 模板文件

项目提供了 6 种博客模板，可直接复制修改：

| 文件 | 类型 |
|------|------|
| `quick-start-template.md` | 快速开始（通用） |
| `tech-tutorial-template.md` | 技术教程 |
| `life-notes-template.md` | 生活随笔 |
| `project-showcase-template.md` | 项目展示 |
| `reading-notes-template.md` | 读书笔记 |
| `ascii-art-demo.md` | ASCII 字符画演示 |

**使用方法**：复制模板文件 → 重命名 → 修改标题和正文内容即可。

## 5. 构建输出 dist 说明

```bash
# 执行构建
npm run build
```

构建流程：
1. `build-check.js` 自检（目录、Pagefind、wrangler、图片大小）
2. `astro build` 生成静态 HTML 到 `dist/` 目录
3. `pagefind` 生成搜索索引到 `dist/pagefind/`

### Cloudflare Pages 硬性限制

| 限制项 | 上限 | 说明 |
|--------|------|------|
| 单文件大小 | 25 MB | dist 内单个文件不能超过 25MB |
| 总文件数 | 20,000 | dist 全部文件总数上限 |

构建自检脚本会自动检查图片大小，超过 25MB 会报错终止构建。

## 6. ASCII 字符画网页渲染说明

### 渲染机制

ASCII 字符画使用 `<pre class="ascii-art">` 标签渲染：

```html
<pre class="ascii-art">
@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
@@@@@@@@@@@@@@@@@@@@@@@@@@@@%#*+=-:...  ..::-=+*#%@@@@@@@@@@
</pre>
```

### CSS 样式适配

- 等宽字体：`JetBrains Mono`, `Fira Code`, `Cascadia Code`, Consolas
- 字号：`0.45rem`（可根据需要调整）
- 行高：`1.15`（紧凑排列）
- 深色背景：`#1e293b`（模拟终端效果）

### 嵌入 Markdown 文章

在 Markdown 文章中直接使用 `<pre class="ascii-art">` 标签包裹 ASCII 文本：

```markdown
## 我的 ASCII 字符画

<pre class="ascii-art">
（ASCII 文本内容）
</pre>
```

## 7. 构建自检说明

`npm run build` 执行前会自动运行 `scripts/build-check.js`：

| 检查项 | 级别 | 说明 |
|--------|------|------|
| 目录结构完整性 | 错误 | src/pages、src/layouts 等必须存在 |
| Pagefind 可用性 | 警告 | 未安装时搜索功能不可用 |
| wrangler.toml 配置 | 警告 | 占位符提示 |
| 图片文件大小 | 错误 | 超过 25MB 终止构建 |
| 图片数量 | 警告 | 接近 20000 时提示 |

**自检不通过 → 构建终止，不会生成损坏的 dist 产物。**

## 8. 一键流水线功能说明

一键流水线在 TUI 工具中执行，完整流程：

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 系统自检  │ ──▶ │ 本地构建  │ ──▶ │ Git 推送  │
└──────────┘     └──────────┘     └──────────┘
   失败终止          失败终止          成功！
```

### 操作步骤

1. 启动 TUI：`npm run tui`
2. 选择 `🚀 一键流水线`
3. 输入提交信息（或直接回车使用默认信息）
4. 等待执行完成

### 执行逻辑

- **自检不通过** → 直接终止，不构建、不推送
- **构建失败** → 终止，输出错误日志
- **构建成功** → 执行 `git add` → `git commit` → `git push`
- **推送成功** → GitHub 自动触发 Cloudflare Pages 部署

### 注意事项

- Cloudflare Pages 需要提前在后台绑定 GitHub 仓库
- 流水线不调用 Cloudflare 部署 API
- 推送后等待 1-3 分钟，Cloudflare Pages 自动完成部署
