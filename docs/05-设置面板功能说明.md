## 1. 如何打开设置面板

在网站任意页面，点击右上角的 **齿轮图标（⚙️）** 即可打开设置面板。

设置面板从右侧滑入，是一个半屏覆盖面板。面板的背景使用半透明毛玻璃效果，不会完全遮挡页面内容。

关闭设置面板的方式：
- 点击面板右上角的 **✕** 按钮
- 点击面板外部的灰色遮罩区域
- 按键盘的 **Esc** 键

## 2. 主题切换

位置：设置面板第一项。

| 选项 | 说明 |
|------|------|
| ☀️ 浅色 | 白色背景，深色文字，适合白天使用 |
| 🌙 深色 | 深色背景，浅色文字，适合夜间或暗光环境 |

主题切换实时生效，不需要刷新页面。选择后系统会记住你的偏好，下次打开网站自动应用。

## 3. 简约模式

位置：设置面板第二项。

### 什么是简约模式

简约模式会**关闭全部装饰特效**，使用最朴素的网页样式。具体包括：
- 关闭毛玻璃效果（背景变为纯色）
- 关闭圆角（所有元素变为直角）
- 关闭阴影（所有阴影效果移除）
- 关闭渐变（颜色过渡变为纯色）
- 关闭 hover 悬停效果
- 关闭动画效果

### 适用场景

- 低配置设备（老电脑、低端手机）浏览更流畅
- 对视觉特效敏感的用户
- 节省设备电量

### 使用方式

- 打开开关：开启简约模式，立即生效
- 关闭开关：恢复所有装饰特效

### 首次访问弹窗

首次访问网站时，会弹出简约模式询问弹窗：

```
是否进入简约模式？
简约模式将关闭全部装饰特效，使用最朴素网页样式，
提升低配设备浏览速度。

[否，保持原样]  [是，开启简约]
```

选择后系统会记住你的选择，不会再次弹出。你也可以随时在设置面板中更改。

> **注意**：简约模式使用 `localStorage` 存储设置，**不需要重新部署**，刷新页面也不会丢失设置。

## 4. 文章列表布局

位置：设置面板第三项。

共有 **5 种布局** 可供选择。切换布局后无需刷新页面，立即生效。

### 4.1 Grid 均等网格（默认）

文章以等宽网格排列，每行固定列数。

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| 列数 | 1 / 2 / 3 / 4 | 3 列 | 每行显示的文章卡片列数 |
| 单页文章上限 | 6 / 12 / 18 / 24 / 36 | 12 篇 | 每页最多显示的文章数量 |
| 卡片最小宽度 | 240 / 280 / 320 / 360 px | 280px | 响应式断点，小于此宽度自动减少列数 |

### 4.2 Masonry 瀑布流

文章以瀑布流方式排列，卡片高度不同，自然堆叠。

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| 列数 | 1 / 2 / 3 / 4 | 1 列 | 瀑布流列数 |
| 单页文章上限 | 6 / 12 / 18 / 24 / 36 | 12 篇 | 每页最多显示的文章数量 |
| 卡片最小宽度 | 240 / 280 / 320 / 360 px | 280px | 响应式断点 |

> **提示**：瀑布流默认单列显示。如果浏览器不支持 JavaScript，瀑布流会自动降级为均等网格布局。

### 4.3 List 纯列表

文章以简洁列表形式排列，每行一篇文章，左侧缩略图，右侧信息。

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| 缩略图尺寸 | 小 / 中 / 大 | 中 | 列表左侧缩略图的大小 |
| 高密度模式 | 开 / 关 | 关 | 开启后行间距更紧凑，显示更多文章 |

### 4.4 Card-List 混合

顶部显示置顶卡片（大卡片），下方显示普通列表。

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| 置顶卡片数量 | 1 / 2 / 3 / 4 / 5 | 3 张 | 顶部显示几张置顶文章的大卡片 |
| 单页文章上限 | 6 / 10 / 15 / 20 | 10 篇 | 每页最多显示的文章数量 |

> **关于置顶**：需要在文章 frontmatter 中手动添加 `pinned: true` 来标记置顶文章。只有标记为置顶的文章才会显示在顶部大卡片区域。

### 4.5 Timeline 时间轴

文章按发布时间排列，左侧显示时间轴线和节点。

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| 轴线样式 | 实线 / 虚线 / 点线 | 实线 | 时间轴连接线的样式 |
| 轴线颜色 | 任意颜色（取色器） | `#6366f1`（紫色） | 时间轴线和节点的颜色 |
| 节点大小 | 小 / 中 / 大 | 中 | 时间轴节点的大小 |
| 单页文章上限 | 10 / 15 / 20 / 30 | 15 篇 | 每页最多显示的文章数量 |

> **重要**：时间轴布局**强制按发布时间倒序排列，不执行置顶逻辑**。即使文章标记了 `pinned: true`，在时间轴布局中也不会置顶。

## 5. 导航交互

位置：设置面板第四项。

共有 **5 种导航样式** 可供选择。切换后无需刷新页面，立即生效。

### 5.1 静态导航（默认）

导航栏固定在页面顶部，始终显示，不随滚动变化。

无额外配置项。

### 5.2 Sticky 固定置顶

导航栏始终固定在页面顶部，滚动时保持可见。

无额外配置项。

### 5.3 下滑隐藏 / 上滑显示

向下滚动页面时导航栏自动隐藏，向上滚动时导航栏重新出现。

| 配置项 | 范围 | 默认值 | 说明 |
|--------|------|--------|------|
| 滚动触发阈值 | 20 - 200 px | 80px | 滚动超过此距离后触发隐藏逻辑 |

### 5.4 滚动透明渐变

导航栏初始为半透明，向下滚动后变为不透明背景。

| 配置项 | 范围 | 默认值 | 说明 |
|--------|------|--------|------|
| 透明度切换阈值 | 20 - 200 px | 50px | 滚动超过此距离后切换为不透明 |

### 5.5 滚动收缩导航

向下滚动时导航栏高度收缩，节省屏幕空间。

| 配置项 | 范围 | 默认值 | 说明 |
|--------|------|--------|------|
| 收缩后导航高度 | 32 - 56 px | 48px | 收缩后导航栏的高度 |

## 6. 卡片风格

位置：设置面板第五项。

共有 **4 种卡片风格** 可供选择。

### 6.1 圆角阴影悬浮（默认）

卡片带有圆角、阴影，鼠标悬停时卡片上浮。

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| 圆角档位 | 小(6px) / 中(10px) / 大(16px) / 超大(20px) | 大(16px) | 卡片圆角大小 |
| 阴影强度 | 轻 / 中 / 重 | 中 | 卡片阴影的深浅 |
| hover 上浮幅度 | 0 / 2 / 3 / 5 / 8 px | 3px | 鼠标悬停时卡片上移的距离 |

### 6.2 简约无边框

极简风格，卡片之间用分割线分隔，无圆角无阴影。

| 配置项 | 范围 | 默认值 | 说明 |
|--------|------|--------|------|
| 分割线粗细 | 0 - 3 px（步长 0.5） | 1px | 卡片之间分割线的粗细 |
| 分割线透明度 | 0.1 - 1（步长 0.1） | 0.5 | 分割线的透明度 |

### 6.3 封面图置顶

卡片顶部显示封面大图，下方显示标题和摘要。

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| 封面高度档位 | 矮(120px) / 中(200px) / 高(280px) | 高(280px) | 封面图区域的高度 |

> **注意**：此风格需要文章配置了封面图（`cover` 字段），无封面图的文章会显示占位符。

### 6.4 背景虚化封面

卡片背景使用封面图的虚化版本，文字叠加在背景上。

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| 封面虚化强度 | 低(2px) / 中(4px) / 高(8px) | 中(4px) | 背景封面图的模糊程度 |

> **注意**：此风格需要文章配置了封面图（`cover` 字段），无封面图的文章会显示默认样式。

## 7. 侧边栏组件

位置：设置面板第六项。

系统提供四类侧边栏相关组件，可以独立开关：

### 7.1 常驻侧边栏

| 属性 | 说明 |
|------|------|
| 默认状态 | 关闭 |
| 功能 | 开启后在页面左侧显示固定侧边栏，包含标签和站点简介 |
| 宽度 | 260px，主内容区域自动右移（margin-left: 260px） |
| 响应式 | 小屏幕（< 1024px）时变为覆盖式侧边栏，不挤占主内容空间 |

> 详见 [侧边栏](#8-侧边栏) 章节。

### 7.2 抽屉侧边面板

| 属性 | 说明 |
|------|------|
| 默认状态 | 开启 |
| 功能 | 右侧滑出的设置面板，用于调整网站各项配置 |
| 交互 | 从右侧滑入，半屏覆盖，点击遮罩或 Esc 键关闭 |

> 即本文档描述的设置面板本身。

### 7.3 文章悬浮 TOC

| 属性 | 说明 |
|------|------|
| 默认状态 | 开启 |
| 功能 | 文章详情页右侧悬浮的目录导航，显示文章各级标题 |
| 子选项 | 阅读位置高亮：开启后在 TOC 中高亮当前阅读位置（仅 TOC 开启时显示） |

### 7.4 标签云

| 属性 | 说明 |
|------|------|
| 默认状态 | 开启 |
| 功能 | 展示所有标签的标签云组件，标签按文章数量调整字号大小 |
| 显示位置 | 侧边栏中的标签区域、标签独立页面 |

所有开关实时生效，不需要刷新页面。

## 8. 侧边栏

当"常驻侧边栏"开关开启后，页面左侧会显示一个固定侧边栏。

### 8.1 布局与尺寸

| 属性 | 说明 |
|------|------|
| 宽度 | 固定 260px |
| 定位 | 固定在页面左侧，随页面滚动保持可见 |
| 主内容 | 主内容区域自动右移，`margin-left: 260px` |
| 小屏幕 | 屏幕宽度 < 1024px 时，侧边栏变为覆盖式（overlay），不挤占主内容空间 |

### 8.2 站点简介

侧边栏顶部显示站点简介区域，包含：

- 站点名称
- 站点描述
- 文章统计（总文章数、已发布文章数）

### 8.3 标签云

侧边栏中显示标签云，标签会根据当前模式进行过滤：

| 当前模式 | 显示的标签 |
|----------|------------|
| 普通模式 | 仅显示普通标签（非黑客标签） |
| 黑客模式 | 仅显示黑客标签（`hacker-` 前缀标签） |

> 标签云中的标签按文章数量调整字号大小，文章数越多字号越大。

### 8.4 交互行为

- 侧边栏开启/关闭由"常驻侧边栏"开关控制，实时生效
- 小屏幕下侧边栏以覆盖方式显示，点击侧边栏外部区域可关闭
- 标签云中的标签可点击，点击后跳转到对应标签的文章列表页

## 9. 毛玻璃效果

位置：设置面板第七项。

### 总开关

控制整个页面的毛玻璃（玻璃拟态 / Glassmorphism）效果。开启后，以下区域会呈现半透明模糊背景：

| 覆盖区域 | 说明 |
|----------|------|
| 导航栏 | 顶部导航栏背景模糊 |
| 页脚 | 页面底部页脚区域 |
| 侧边栏 | 左侧常驻侧边栏背景 |
| 搜索弹窗 | 搜索弹窗的背景面板 |
| 设置面板 | 右侧滑出的设置面板 |
| 文章卡片 | 文章列表中的卡片背景 |

### 模糊强度

仅在总开关开启时显示，强度档位真正生效：

| 级别 | 模糊值 | 说明 |
|------|--------|------|
| 低 | 4px | 轻微模糊，背景隐约可见 |
| 中（默认） | 8px | 中等模糊，最常用的效果 |
| 高 | 16px | 强模糊，背景几乎不可辨认 |

### 关闭与禁用

| 场景 | 行为 |
|------|------|
| 总开关关闭 | 完全移除 `backdrop-filter` 属性，不保留模糊计算，减少 GPU 开销 |
| 简约模式开启 | 强制禁用毛玻璃效果，背景变为纯色 |

> **提示**：如果在简约模式下，毛玻璃效果会被自动关闭。关闭简约模式后可重新开启。

## 10. 页面动效

位置：设置面板第八项。

### 总开关

控制整个页面的动画效果。关闭后所有动画效果（淡入、滑动、卡片入场等）都会立即停止，元素直接显示。

### 动画模式

仅在总开关开启时显示：

| 模式 | 说明 |
|------|------|
| 淡入淡出（默认） | 元素从透明渐变到不透明 |
| 滑动推入 | 元素从下方滑入 |
| 缩放 | 元素从小变大 |
| 翻转 | 元素从背面翻转过来 |

### 动画时长

仅在总开关开启时显示：

| 级别 | 时长 | 说明 |
|------|------|------|
| 快 | 150ms | 快速切换，几乎感觉不到延迟 |
| 标准（默认） | 300ms | 自然的过渡速度 |
| 慢 | 600ms | 舒缓的动画，适合展示 |

### 卡片视口入场动画

仅在总开关开启时显示。控制文章卡片是否在滚动到视口时才播放入场动画。关闭后卡片直接显示，不等待滚动。

## 11. 站点信息

位置：设置面板最底部。

显示当前博客的基本信息：

| 信息项 | 来源 |
|--------|------|
| 站点名称 | 从 API 读取（`/api/config`），默认显示"林天策 Blog" |
| 作者 | 从 API 读取 |

> **注意**：站点名称区域也是**隐秘黑客模式的触发入口**。连续快速点击站点名称 5 次（2 秒内）可以触发黑客模式。详见 [隐秘黑客模式使用教程](./06-隐秘黑客模式使用教程.md)。

## 12. 站点健康检测

位置：设置面板底部，站点信息下方。

站点健康检测内嵌在设置面板中，不再以浮动按钮形式展示。用于检测站点运行状态，帮助用户快速排查问题。

### 检测项目

点击"开始检测"后，系统会自动检测以下项目：

| 检测项目 | 检测内容 | 说明 |
|----------|----------|------|
| 页面加载时间 | 当前页面完整加载耗时 | 使用 Performance API 获取 |
| 资源加载 | CSS、JS、图片等资源是否正常加载 | 检测关键资源是否 404 |
| 关键页面可访问性 | 首页、文章页、标签页等是否可访问 | 通过 fetch 检测返回状态码 |
| LocalStorage | 浏览器本地存储是否可用 | 读写测试，检测配额是否已满 |
| Service Worker | SW 是否注册、是否激活 | 检测离线缓存状态 |
| 网络类型 | 当前网络连接类型 | 4g / wifi / 3g / 2g / slow-2g |
| 关键文件 | robots.txt、sitemap.xml 等是否存在 | 检测关键文件返回状态 |
| 用户设置 | localStorage 中设置数据是否完整 | 检测设置键是否存在、数据是否可解析 |

### 检测结果

检测结果以列表形式展示，每个项目有对应的状态图标：

| 状态 | 图标 | 说明 |
|------|------|------|
| 正常 | ✅ | 检测通过，该项工作正常 |
| 警告 | ⚠️ | 存在潜在问题，但暂不影响使用 |
| 错误 | ❌ | 检测失败，需要关注 |

### 操作按钮

检测完成后，提供两个操作按钮：

| 按钮 | 说明 |
|------|------|
| 🔄 重新检测 | 清除缓存结果，重新执行全部检测 |
| 📥 导出检测日志 | 将检测报告保存为 `.txt` 文件，包含完整检测结果、时间戳、各项指标详情 |

导出的日志文件命名格式为 `site-health-check-YYYY-MM-DD-HHmmss.txt`，内容包含：
- 检测时间
- 当前页面 URL
- 用户代理信息
- 各项检测的详细结果和状态
- 建议修复措施（针对警告和错误项）

### 缓存机制

- 检测结果会缓存到 `localStorage`，键名为 `site_health_check_result`
- 缓存有效期：**1 小时**。超过 1 小时后将自动清除缓存，下次打开设置面板时需重新检测
- 点击"重新检测"按钮会清除缓存并立即执行新检测

## 13. 设置存储说明

### 存储方式

所有设置面板的配置都存储在浏览器的 **localStorage** 中，使用键名 `lintiance_settings`。

### 存储特性

| 特性 | 说明 |
|------|------|
| 存储位置 | 浏览器本地（localStorage） |
| 是否持久化 | 是，关闭浏览器后保留 |
| 是否需要重新部署 | 否，纯前端设置 |
| 是否跨设备同步 | 否，每台设备独立存储 |
| 清除方式 | 清除浏览器数据会丢失设置 |

### 默认值

当 localStorage 中没有存储的设置时，所有选项使用默认值（见上述各节）。清除浏览器数据后，设置会恢复为默认值。

### 配置优先级

```
用户设置（localStorage） > 云端配置（KV） > 代码默认值
```

即：用户在前端修改的设置具有最高优先级，会覆盖云端配置和代码默认值。
