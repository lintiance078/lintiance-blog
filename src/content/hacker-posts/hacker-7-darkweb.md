## 2. Tor 洋葱路由原理

```
    Client                    Tor Network
       │                           │
       │  ┌─────┐    ┌─────┐    ┌─────┐
       ├──┤Guard├────┤Relay├────┤Exit ├─── Internet
       │  └─────┘    └─────┘    └─────┘
       │     ▲          ▲          ▲
       │     └──────────┴──────────┘
       │        三层加密 (洋葱)
       │
```

### 加密层次

```
    ┌──────────────────────┐
    │  Layer 3 (Exit Key)  │ ← 出口节点解密
    ├──────────────────────┤
    │  Layer 2 (Relay Key) │ ← 中继节点解密
    ├──────────────────────┤
    │  Layer 1 (Guard Key) │ ← 入口节点解密
    ├──────────────────────┤
    │     Original Data    │
    └──────────────────────┘
```

## 3. 隐藏服务 (.onion)

```
    Service ──→ Introduction Points (发布)
                    │
    Client ────→ Rendezvous Point (会合点)
                    │
    Service ←──→ Client (通过 RP 通信)
    
    6 跳连接，完全匿名化双方
```

## 4. I2P vs Tor

| 特性 | Tor | I2P |
|------|-----|-----|
| 路由方式 | 洋葱路由 (单向隧道) | Garlic Routing (双向隧道) |
| 网络层 | TCP 流 | UDP/NTCP 包交换 |
| 隐藏服务 | .onion | .i2p (eepsites) |
| P2P 支持 | 不推荐 | 原生支持 |
| 延迟 | 较高 | 较高（但 P2P 友好） |

## 5. Garlic Routing 示意

```
    ┌─────────────────────────────────┐
    │          Garlic Clove           │
    │  ┌───────────────────────────┐  │
    │  │  Delivery Instructions    │  │
    │  ├───────────────────────────┤  │
    │  │  Encrypted Message        │  │
    │  │  ┌─────────────────────┐  │  │
    │  │  │  Clove for Next Hop │  │  │
    │  │  └─────────────────────┘  │  │
    │  └───────────────────────────┘  │
    └─────────────────────────────────┘
    
    多个 "蒜瓣" 可以打包在一个消息中
    每个蒜瓣有不同的传递指令
```

## 7. 最佳实践

- 禁用 JavaScript (NoScript)
- 使用 Tails OS 或 Whonix
- 不要最大化浏览器窗口 (防止指纹识别)
- 不要通过 Tor 登录个人账户
- 使用桥接中继绕过审查
