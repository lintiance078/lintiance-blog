# Hello World - 欢迎来到 Rin Blog

这是 Rin Blog 的第一篇文章。

## 关于 Rin Blog

Rin Blog 是一个基于 Astro + Cloudflare Pages 的轻量级个人博客系统，UI 风格参考 [Rin](https://github.com/lintiance078/Rin)。

### 技术栈

- **前端框架**：Astro（静态站点生成）
- **部署平台**：Cloudflare Pages
- **数据库**：Cloudflare D1（文章元数据）
- **存储**：Cloudflare KV（站点配置、友链）
- **搜索**：Pagefind（构建期索引）
- **本地工具**：Windows TUI（基于 Node.js + blessed）

### 特性

- 🎨 Rin 风格 UI（文章卡片、侧边设置面板、健康检测）
- 🔍 全文搜索（Pagefind 构建期索引）
- 📱 响应式布局
- 🎯 仅 GET 只读接口，安全可靠
- 🖼️ 支持普通图片与 ASCII 字符画
- 🛠️ Windows TUI 本地管理工具
