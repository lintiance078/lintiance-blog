# 【ASCII 字符画演示】图片转 ASCII 效果展示

## 什么是 ASCII 字符画？

ASCII 字符画是将普通图片通过灰度映射算法，转换为由字符组成的画面。每个像素的亮度对应一个特定字符，从而在终端或网页上呈现出可辨认的图像。

## 字符集说明

本工具使用**多级灰度字符集**，默认为 `detailed` 级别：

```
@ % # * + = - : .  (空格)
```

从最暗 `@` 到最亮 ` `（空格），共 10 级灰度，足以还原丰富的图像细节。

## 如何使用 TUI 转换图片

### 单张图片转换

1. 启动 TUI 工具：`npm run tui`
2. 选择 `🖼️ 图片处理` → `🎨 单张图片转 ASCII`
3. 输入图片路径（相对于 `public/assets/images/`）
4. 确认风险后开始转换

### 批量自动转换

1. 启动 TUI 工具
2. 选择 `🖼️ 图片处理` → `📦 批量转换旧图片为 ASCII`
3. 确认风险提示后执行

## 转换参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| maxWidth | 120 | 字符画最大宽度 |
| charset | detailed | 字符集：detailed / standard / simple / blocks |
| contrast | 1.0 | 对比度增强系数 |
| brightness | 1.0 | 亮度系数 |

## 注意事项

⚠️ **重要提示**：
- ASCII 字符画为灰度画面，画质相比原图会有下降
- 批量转换会**删除原图片文件**，建议提前备份
- 仅转换超过设定天数的旧图片，新图片保留原格式
- 可在 TUI 设置中调整阈值和自动转换开关
