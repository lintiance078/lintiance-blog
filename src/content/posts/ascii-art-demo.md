# ASCII 字符画生成指南：从图片到字符的艺术转换

ASCII 字符画是一种将普通图片通过灰度映射算法转换为字符组合的艺术形式。每个像素的亮度对应一个特定字符，从而在终端或网页上呈现出可辨认的图像。

## 转换原理

ASCII 字符画的转换过程分为几个步骤：

1. **读取图片**：加载原始图片文件
2. **灰度转换**：将彩色图片转为灰度图，每个像素获得 0-255 的亮度值
3. **字符映射**：将亮度值映射到预定义的字符集中
4. **输出渲染**：将字符按行列排列，生成了最终的字符画

## 字符集选择

TUI 工具提供多种字符集预设：

| 字符集 | 包含字符 | 适用场景 |
|--------|----------|----------|
| `detailed` | `@%#*+=-:. ` | 高精度还原，适合细节丰富的图片 |
| `medium` | `@#*+=-. ` | 中等精度，适用大多数场景 |
| `simple` | `#*-. ` | 简洁风格，适合简单图形 |
| `blocks` | `█▓▒░ ` | 方块风格，有独特的视觉效果 |

## 使用 TUI 转换

### 单张转换

1. 启动 TUI 工具：`npm run tui`
2. 选择 `🖼️ 图片处理` → `🎨 单张图片转 ASCII`
3. 输入图片路径（相对于 `public/assets/images/`）
4. 选择字符集和宽度
5. 确认后生成 ASCII 字符画

### 批量转换

1. 选择 `🖼️ 图片处理` → `📦 批量转换旧图片为 ASCII`
2. 设置天数阈值（超过此天数的图片会被转换）
3. 确认风险提示后执行

## 参数说明

- **最大宽度**：控制字符画的列数，60-150 之间合适
- **对比度**：调整亮度映射的对比度，1.0 为默认
- **亮度**：整体亮度偏移，1.0 为默认

## 网页渲染

字符画在网页上使用 `<pre>` 标签渲染，配合等宽字体（JetBrains Mono / Fira Code）获得最佳效果。暗色模式下字符画对比度更佳。

## 注意事项

- ASCII 字符画是灰度画面，画质相比原图会有所下降
- 批量转换会删除原图片文件，建议提前备份
- 建议在暗色模式下查看字符画，对比度更好
